# 🚀 OptiCore

**Performance Optimization Addon for LibreELEC/CoreELEC**

[![LibreELEC](https://img.shields.io/badge/LibreELEC-Supported-brightgreen?logo=raspberry-pi)](https://libreelec.tv)
[![CoreELEC](https://img.shields.io/badge/CoreELEC-Supported-blue?logo=raspberry-pi)](https://coreelec.org)
[![License: GPL v2](https://img.shields.io/badge/License-GPL%20v2-blue.svg)](LICENSE)

---

## ✨ Features

- **Clear Kodi/System/YouTube Cache**
- **Overclock Control** (Raspberry Pi & SBCs)
- **Optional Auto-Clean Mode** (set interval)
- **Modern GUI for Settings**
- **Safe & Easy to Use**

## 🛠️ Installation

1. **Download** the latest release from [GitHub Releases](https://github.com/Nigel1992/OptiCore/releases)
2. In Kodi, go to **Add-ons > Install from zip file**
3. Select the downloaded `.zip` file
4. Configure via **Add-on Settings**

---

## ⚡ Usage

- **Auto-Clean:** Enable and set interval in hours
- **Manual Clean:** Use the "Clear Cache Now" button
- **Overclock:** Enable and set frequencies (requires reboot)

> ⚠️ **Warning:** Overclocking can cause instability or hardware damage. Use at your own risk!

---

## 💡 Supported Platforms

- LibreELEC/CoreELEC (Raspberry Pi, Odroid, and other SBCs)
- Kodi 20+ (Python 3)
